# ComfyUI Blender 8-Way + AI Portrait

A Windows-first ComfyUI custom node pack and ready-to-load workflow with two independent outputs:

- eight transparent Blender renders of a selected 3D model, at fixed 45-degree directions;
- an AI character portrait driven only by the text prompt and optional LoRAs.

The repository is under active construction. Model weights and generated media are intentionally excluded.

## Target environment

- ComfyUI Desktop on Windows
- Blender 4.3 or newer
- [ComfyUI-LoRA-Manager](https://github.com/willmiao/ComfyUI-Lora-Manager)
- an SDXL-compatible checkpoint
